BRUTUS SHIELD v0.3.0 — UPDATE EXISTING GITHUB PROJECT

1. Download BrutusShield_v0.3.0_Update.zip into Android Downloads.
2. In Termux run:

cd ~/BrutusShield/BrutusShield
UPDATE=$(ls -t ~/storage/downloads/BrutusShield_v0.3.0_Update*.zip | head -n 1)
unzip -o "$UPDATE" -d .
git add .
git commit -m "Brutus Shield v0.3.0 offline malware engine"
git push

3. Watch the cloud build:

RUN_ID=$(gh run list --limit 1 --json databaseId --jq '.[0].databaseId')
gh run watch "$RUN_ID" --exit-status

4. Download the finished APK:

mkdir -p ~/storage/downloads/BrutusShield-v0.3.0
gh run download "$RUN_ID" -n BrutusShield-v0.3.0-debug -D ~/storage/downloads/BrutusShield-v0.3.0
termux-open ~/storage/downloads/BrutusShield-v0.3.0/BrutusShield-v0.3.0-debug.apk
